Users API

Base URL: /api/users

GET/api/users?from=0&limit=5

List active users with pagination.

POST/api/users

Create a user and encrypt the password.

PUT/api/users/:id

Validate the MongoDB ID and update a user.

PATCH/api/users/:id

Partially update the supplied user fields.

DELETE/api/users/:id

Deactivate a user with a soft delete.

Create a user

Use a unique email, a password of at least six characters, and a registered role.

Built-in safeguards

Email format and uniqueness checks, database role validation, bcrypt password hashing, and sanitized JSON responses.

{
  "name": "Sebastian",
  "email": "sebastian@example.com",
  "password": "Test1234",
  "role": "ADMIN_ROLE"
}

Parallel by design

Promise.all runs the user query and total count concurrently. Because neither operation depends on the other, this reduces response time while keeping both results synchronized—and rejects the request if either operation fails.
